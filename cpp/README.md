# QuizLab C++

Varian QuizLab untuk latihan dasar pemrograman C++ tingkat SMP.

## Materi

1. **Dasar Program C++** — struktur program, `#include <iostream>`, `main()`, `cout`, `cin`, `endl`, komentar, tanda kurung kurawal, dan `return 0`.
2. **Variabel, Tipe Data, dan Operator** — `int`, `float`, `double`, `char`, `string`, `bool`, operator aritmetika, perbandingan, logika, modulus, dan assignment.
3. **Percabangan** — `if`, `if-else`, `else if`, nested if, `switch-case`, `break`, dan `default`.
4. **Perulangan** — `for`, `while`, `do-while`, accumulator, nested loop, `break`, dan `continue`.

## Menjalankan

Buka folder `cpp/` melalui GitHub Pages atau jalankan `cpp/index.html` dengan Live Server.

- Bank soal: `cpp/js/questions.js`
- Mesin CBT: `cpp/js/app.js`
- Tampilan: `cpp/css/`
- Ikon: `cpp/assets/icons.svg`

## Konfigurasi ujian

Bank berisi 60 soal (15 per kelompok materi). Satu sesi berisi 50 soal dengan durasi maksimal 45 menit, dipilih secara acak dengan komposisi 12 mudah, 26 sedang, dan 12 sulit.

Batas akhir pengerjaan: **Selasa, 17 November 2026 pukul 14.50 WIB**. Setelah waktu tersebut akses ditutup dan sesi yang sedang berlangsung diakhiri otomatis.

## Google Sheets

QuizLab C++ menggunakan URL Google Apps Script yang sama dengan QuizLab utama dan QuizLab Word. Data yang dikirim tetap nama peserta, waktu submit server, dan nilai akhir. Tidak ada Apps Script baru dan tidak ada perubahan pada `../apps-script/Code.gs`.
